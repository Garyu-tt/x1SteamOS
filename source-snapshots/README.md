# R20 patched source-file snapshots

All 16 complete Linux kernel files changed by the confirmed bootable R20 patch series are mirrored here for easy GitHub browsing and review. These files were extracted from the exact upstream Git commit with the two R20 patches applied in order. **This directory is not a standalone source tree**. To compile, reconstruct the complete kernel using `./scripts/fetch-enigma.sh r20` at repository root. R21 remains a separate unbooted candidate patch in `patches/experimental/`.
